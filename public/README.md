# Static assets

Drop the following files here to replace the built-in placeholders:

- **`cv.pdf`** — linked from the Hero "Download CV" button (`/cv.pdf`).
- **`og.png`** — 1200×630 social share image referenced in `app/layout.tsx`
  (`/og.png`). Used for Open Graph + Twitter cards.

`favicon.svg` is already provided. Anything in this folder is served from the
site root (e.g. `public/cv.pdf` → `https://peterantoun.com/cv.pdf`).
